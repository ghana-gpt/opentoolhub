# Getting started

Welcome to OpenToolHub.

This project is designed to help people discover useful tools, APIs, data sources, and starter stacks for building real-world products and AI workflows.

## What you need

- a GitHub account
- a willingness to contribute ideas, examples, or tool recommendations
- curiosity about public APIs, open data, and useful digital systems

## Recommended first steps

1. Read the main [README.md](../README.md)
2. Review the [ROADMAP.md](../ROADMAP.md)
3. Explore the project structure and contribution guidelines
4. Pick a contribution area that matches your interest

## Good first tasks

- add a relevant public API or data source
- suggest a new use case
- improve documentation
- create a starter template for a common app idea
- document a practical stack for AI or civic technology

## Contribution workflow

1. Fork the repository.
2. Create a branch.
3. Add your work.
4. Submit a pull request.

## Project principles

- useful over flashy
- practical over theoretical
- inclusive over exclusive
- community over ego
- clarity over complexity

This project grows best when people contribute examples and practical value.
