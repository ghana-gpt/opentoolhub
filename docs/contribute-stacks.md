# Contribute a stack

OpenToolHub grows through community input.

This page explains how to contribute practical stacks, use cases, and examples to the project.

## What to contribute

You can contribute any of these:

- a new use case
- a tool category or subcategory
- a stack recommendation for a product idea
- a starter template
- notes on what works well in a real workflow
- a public-interest project example
- a better explanation of a common app pattern

## Good contribution examples

A strong contribution usually includes:

- a short description of the product idea
- the problem it solves
- the categories involved
- the suggested tools or API types
- why this stack is useful
- any lessons learned or caveats

## Example contribution format

```text
Name: Travel planning stack
Use case: travel and local discovery
Categories: weather, maps, local data, currency
Tools: weather API, map service, local directory, exchange rate API
Why it matters: helps users plan trips with better context and local awareness
Notes: works well for a city or trip-planning experience
```

## Contribution principles

- be practical and specific
- focus on real product ideas
- help people build faster
- keep the guidance clear and useful
- prefer examples over vague lists

## Contribution flow

1. Decide on a use case or tool stack
2. Add a clear summary
3. Describe the categories and purpose
4. Explain the real-world value
5. Open a pull request or issue with the contribution

## Why this matters

The project becomes stronger when contributors share what they have actually built, tested, or learned.

That is how OpenToolHub grows from a basic starter into a useful ecosystem.
