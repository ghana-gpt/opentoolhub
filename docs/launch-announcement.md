# Launch announcement

OpenToolHub is a new open-source project focused on helping people discover the right public tools for the project they want to build.

We are building a practical discovery layer for:

- public APIs
- open datasets
- AI-ready services
- no-code and automation tools
- real-world product stacks

## What makes this project different

Instead of being just a generic directory, OpenToolHub is organized around use cases and builder needs.

The project helps people answer:

- what kind of tools fit this idea?
- which categories matter most?
- what stack should I start with?
- how do I turn a concept into a prototype?

## The first goal

The first version of the project focuses on a small but useful set of real-world directions:

- travel and local discovery
- city dashboards
- AI research workflows
- public-health and civic tools
- startup MVPs

## Why this matters

Public tools are abundant, but their value is often hidden behind fragmented discovery and scattered docs.

OpenToolHub is built to make that easier.

## Contribute

We welcome contributions from builders, AI practitioners, civic-tech contributors, students, and anyone working with public tools in practical ways.

If you have a stack idea, starter template, or real-world use case, we would love to hear about it.
