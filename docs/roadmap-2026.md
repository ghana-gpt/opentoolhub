# Roadmap 2026

This roadmap is designed to guide the next growth phase of OpenToolHub.

## Phase 1: clarify the product story

- define a clear mission statement
- keep the repo focused on use-case-based discovery
- make the landing page and README consistent
- emphasize original product positioning

## Phase 2: improve practical value

- add more stack recommendations
- add better use-case pages
- improve template quality
- add examples and notes for real builders

## Phase 3: activate the community

- add issue templates for features and stack suggestions
- encourage field-specific contributions
- collect public-good and AI-related use cases
- surface the most useful stack examples

## Phase 4: strengthen the launch narrative

- create a cleaner docs site and homepage
- publish the first featured examples
- test the discovery flow with real workflows
- improve onboarding for new contributors

## Phase 5: expand the ecosystem

- add more templates for civic, startup, and AI use cases
- support more no-code and automation flows
- integrate user-submitted stacks and examples
- keep the project focused on practical public-tool discovery

## Long-term direction

OpenToolHub should become a practical discovery layer for public tools, data sources, and AI-ready workflows. It should help builders move from idea to prototype faster, with less friction and more clarity.
