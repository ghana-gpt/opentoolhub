# Featured stacks

This page highlights the first set of stack ideas that OpenToolHub will prioritize.

## 1. Travel planner stack

### Core idea
A tool that helps people plan travel based on weather, maps, local activity, and destination information.

### Suggested categories
- weather
- map and geolocation
- currency exchange
- local discovery
- calendar or holiday data

### Example stack
- weather API
- map and routing service
- local attractions or city directory
- exchange rate API
- holiday or travel-date API

### Use case
- travel planning
- itinerary support
- trip comparisons
