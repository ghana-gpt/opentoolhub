# AI research assistant example

## Product idea

An AI-powered assistant that helps a user gather, summarize, and compare information from multiple public sources.

## Problem it solves

Researchers, students, and general users often need better ways to collect public information, compare sources, and turn raw facts into usable knowledge.

## Suggested stack

- search or retrieval layer
- public knowledge or news sources
- translation or language tools
- summarization or reasoning services
- document or source indexing tools

## Feature ideas

- topic exploration assistant
- source comparison summaries
- timeline or trend extraction
- localized or multilingual output
- follow-up question support with citations or references

## Example user flow

1. User asks a question or research prompt.
2. The assistant finds relevant public sources.
3. It extracts and ranks useful facts.
4. The system summarizes the result into a concise answer.
5. The user can ask follow-up questions or request more detail.

## Why this matters

This is one of the clearest examples of how public tools and AI workflows can combine to create helpful, real-world products.
