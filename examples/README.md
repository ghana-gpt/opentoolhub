# Examples

This folder contains practical example projects that show how OpenToolHub turns real product ideas into stack suggestions and starter patterns.

Each example is intentionally lightweight and grounded in a real-world problem. The point is not to produce a full production app, but to help a builder understand what categories of public tools matter and how they fit together.

## Included examples

- Travel planner
- City dashboard
- AI research assistant
- Startup MVP
- Public health tracker

## How to use these examples

1. Pick a problem you want to solve.
2. Read the suggested stack.
3. Review the user flow and feature ideas.
4. Map the concept to the relevant categories in the project.
5. Use the example as a starting point for your own project or contribution.

These examples are meant to grow over time as the community adds more real-world patterns.
