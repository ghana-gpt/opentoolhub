# Startup MVP starter

This starter is designed for quick product validation using public tools rather than building everything from scratch.

## Typical problem

A builder wants to test an idea quickly with a small product that uses public data, APIs, and simple interfaces.

## Suggested stack

- map or local search API
- public dataset or open service
- finance or market data service
- analytics or event tracking layer
- simple dashboard or web UI

## Example flow

1. Idea is defined in a small product brief
2. Public data is connected to a simple workflow
3. User can interact with the product in a prototype form
4. Product metrics and early user behavior are tracked
5. The idea is refined based on actual usage

## Recommended features

- a narrow and clear user problem
- a simple interface for testing the concept
- real public data integration
- small feedback loop
- low-cost iteration path

## Best use cases

- local discovery tools
- niche data products
- idea validation apps
- internal tool prototypes
- public data dashboards

## Why this matters

The goal is not to build a large platform immediately. The goal is to validate a useful idea quickly, cheaply, and clearly.
