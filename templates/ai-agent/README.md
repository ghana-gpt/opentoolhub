# AI agent starter

This starter is designed for AI-powered workflows that gather, summarize, and act on public data and digital tools.

## Typical problem

A user wants an AI helper that can provide useful answers using live information, context, and the right tools.

## Suggested stack

- search or retrieval layer
- public knowledge or news source
- language or translation service
- summarization or reasoning tool
- workflow or orchestration layer

## Example flow

1. A user asks a natural-language question
2. The assistant identifies relevant data sources
3. Public tools and sources are used to gather context
4. The output is summarized and presented clearly
5. The user can ask follow-up questions or take action

## Recommended features

- clear prompt and tool routing
- structured retrieval from public sources
- summarization and ranking
- context-aware follow-up interaction
- simple user experience with useful results

## Best use cases

- research assistants
- local recommendation agents
- startup tool exploration
- public data assistants
- productivity and planning agents

## Why this matters

AI tools become far more useful when they have access to the right external tools, sources, and workflows.
