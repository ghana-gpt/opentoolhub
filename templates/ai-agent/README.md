# AI agent starter

This template is designed for AI assistants or agent workflows powered by public tool access.

## Typical use case

- research assistant
- trip planning assistant
- local recommendations agent
- business intelligence helper

## Suggested stack

- GNews
- Wikipedia API
- translation service
- weather and maps APIs
- retrieval or vector search tools

## Example flow

1. Receive a user request in natural language
2. Match it to a relevant tool stack
3. Collect structured data from public APIs
4. Summarize or synthesize the result
5. Return a clear, action-oriented answer
