# Civic dashboard starter

This starter is designed for local information systems, community dashboards, and civic-tech products.

## Typical problem

A person or organization wants a simple local dashboard that brings together useful public information, neighborhood context, and updates.

## Suggested stack

- map or geolocation service
- weather or environmental feed
- public data source
- local event or community source
- alert or reporting feed

## Example flow

1. A user opens a city or community dashboard
2. Relevant map layers and local context load
3. Weather and environment updates appear
4. Local events, alerts, or public updates are shown
5. The user gets an easy summary of what matters most

## Recommended features

- map view
- city-level filters
- local summary cards
- event and update panels
- public-interest categories
- low-friction navigation

## Best use cases

- neighborhood guides
- local civic dashboards
- local community portals
- public information systems
- simple city-level status tools

## Why this matters

A civic dashboard becomes useful when it reduces search and friction for the user. The goal is not to flood them with data — it is to surface the information that matters most in a useful format.
