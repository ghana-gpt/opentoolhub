About this starter

Choose a country and an indicator. The page shows the latest published value, the change since the first available year, the trend, and a like-for-like comparison with the other countries in the snapshot. Every number links back to the World Bank series it came from.

Data and method

Refresh the snapshot with python3 scripts/fetch_data.py, then reload the page. The app never calls the API from the browser, so it also works from a laptop with no network.
